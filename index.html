Security

I hunt bugs on public programs and build my own recon tooling to do it. LLEO started as a pile of scripts and is turning into a planner, executor and critic loop with a strict scope engine, because automation without guardrails is just noise with a speed boost.

How I work

  • Scope first. Every target is checked against program rules before a single request goes out.
  • Recon is automated, judgment isn't. Humans approve anything that touches a live system.
  • Disclosure follows the program's policy, every time.
